# TicketFlow 用户端操作手册

适用对象：工单申请人。版本：2026-10-21 分析与登录保持版。

## 1. 打开系统与申请账号

访问 https://8.159.144.194/ticketflow/ 。推荐使用近期版本的 Chrome、Edge 或 Safari。点击“申请注册”，填写账号、姓名与密码并确认密码。账号为3–40位字母、数字、下划线、点或短横线，首位为字母或数字；密码至少12位。提交后需要管理员审核，通过后才能登录。请勿重复提交相同账号。

## 2. 登录、保持登录与退出

填写账号与密码，点击“登录工作台”。“保持登录30天”默认选中，在同一浏览器中关闭页面再打开可恢复会话；浏览器必须允许本站 Cookie。这个期限从本次登录开始计算，不会因使用而无限延期。公共电脑请取消勾选，并在离开前点击“退出”。未勾选时凭据最长8小时，浏览器可能在恢复窗口时恢复会话 Cookie，因此公共电脑必须主动退出。

系统将登录凭据保存在 HttpOnly Cookie 中，不在本地存储中保存明文密码。清除 Cookie、切换浏览器、无痕窗口关闭、会话到期、账号停用或密码修改后，需要重新登录。“退出”会使此账号现有会话一并失效。不要将管理员的首次登录信息转给其他人。

忘记密码时联系管理员；当前版本没有自助邮箱找回功能。

## 3. 查看工作台和工单

工作台显示你有权查看的工单数量、状态和近期更新。点击状态卡片可查看对应工单。“工单中心”支持关键字、状态、类型、优先级等筛选以及分页。普通用户只能查看自己提交的工单；其他人的工单不能通过猜测编号访问。

状态含义：待受理＝等待处理；处理中＝团队正在处理；待确认＝处理方提交解决结果，等待你确认；已关闭＝你已确认完成；已取消＝管理员取消该工单。

## 4. 提交工单

点击“新建工单”，填写简明标题、详细问题描述、工单类型、优先级，按实际情况选择处理组。ERP问题可写明功能菜单、单据号、操作时间、报错提示和复现步骤；运维工单可写明受影响系统、时间和影响范围。确认后提交。

优先级应反映业务影响，紧急适用于关键业务中断。请勿在正文或附件中填写密码、访问密钥等敏感信息。

## 5. 补充说明与附件

在工单详情填写评论并提交，可补充复现步骤或验收结果。普通用户看不到处理团队的内部备注。

上传支持 PNG、JPEG、PDF、UTF-8 TXT/CSV；每个文件最大10 MiB，每张工单最多20个附件。扩展名与文件内容必须匹配，空文件不支持。附件属于工单内容，具备该工单查看权限的人可以下载；不要上传仅打算私发给某人的资料。当前版本不支持删除或替换附件，提交前请核对。

## 6. 验收、退回和重新打开

工单为“待确认”时，检查处理结果：问题已解决则确认关闭；未解决则退回处理中，并写明原因。已关闭后问题再次出现，可重新打开，同样必须填写原因。普通申请人不能分派工单、修改处理组或取消工单。

多人同时操作时，系统可能提示内容已更新。请刷新工单、确认最新记录，再提交操作，避免覆盖同事的修改。

## 7. 个人设置

打开“个人设置”查看账号信息。修改密码需要输入当前密码、新密码并确认；新密码至少12位。修改成功后重新登录，旧会话失效。当前版本姓名、团队和账号启停由管理员维护。

## 8. 常见问题

账号密码正确但不能登录：确认注册已获批、账号未停用，检查大小写和空格。系统繁忙或操作过于频繁时按提示稍后重试，不要连续点击。

关闭页面后需要登录：确认“保持登录30天”已选中；检查是否使用无痕模式或自动清除 Cookie；确认管理员未停用账号，且你没有在其他页面退出或修改密码。

附件无法上传：检查格式、大小、工单附件总数和UTF-8编码。工单找不到：确认是否本人提交、筛选条件是否过窄。网络错误：先刷新页面；问题持续时记录操作时间和提示，联系管理员。

操作手册可在左侧“操作手册”查看并下载。分析与报表是管理员功能，普通用户不显示此入口。
